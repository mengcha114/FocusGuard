# FocusGuard 锁机加固与功能改进计划

## 第一批：锁机绕过与卡死修复（优先）

1. 暂停/番茄钟改用单调时钟（`LockState.kt`）
   - `pauseUntil`、`pomodoroEnd` 改为 elapsedRealtime 基准 + 时长；重启校准逻辑同步覆盖。
   - 时间篡改检测移到 `guardTick` 中 `shouldBlockNow` 判断之前（暂停期间也检测）。
2. 篡改惩罚只罚一次：`applyTamperPenalty` 后重锚 `lockWallBase`。
3. 番茄钟阶段推进移入 `LockGuardService.guardTick()`；Compose/悬浮窗只读显示。
4. 锁机不可被覆盖：`startLock` 在已锁机（含暂停）时只允许延长，解锁强度取较高者；`TimerLockScreen` 锁机/暂停期间只读，`LockToolExecutor` 同样受约束。
5. 防清后台
   - Dhizuku 下调用 `setUserControlDisabledPackages`（禁强停/清数据），随锁机状态开关，`onDestroy` 兜底解除。
   - 心跳中断时长补回锁机剩余（新增 `LockState.extendBy`，并记录被杀时剩余时长）。
6. 设置页放宽判定改为“收紧白名单”：白名单、敏感应用、隐私开关、置信度、API 配置、提示词、调用上限、省 token 项等一律视为放宽需答题；锁机期间禁止修改锁机相关设置。

## 第二批：年龄段与题库

1. 首次强制选择年龄段（小学/初中/高中/大学及以上），确认页倒计时 + 输入确认；之后只能调高，调高需答题；锁机期禁止修改；独立 prefs 存储，Download 目录标记兜底。
2. `ChallengeGenerator` 按年级 × 强度出题：
   - 小学：大数四则（7–8 位加减含连加连减、3×3/4×4 位乘、保证整除的除法、混合运算）。
   - 初中及以上：在大数运算基础上叠加本年级题型。
3. 题型丰富与防重复
   - 每个年级至少 15 类题型（小学：连加、连减、加减混合、大数乘、整除除法、带余除法、多步混合运算、括号运算、乘方、平方差、百分比、进制换算、倍数计数、年龄/行程/工程应用题等），每类内部随机参数和多种题干模板。
   - 去重：持久化最近 200 道题的指纹（题型 + 参数哈希），新题命中则重新生成；同一题型不连续出现，最近 5 题内同类最多 1 次。
   - 题型轮换：按“最近出现次数”降低权重，保证均匀覆盖，而不是固定权重抽签。
   - 随机源用 `SecureRandom`，避免可预测。
   - 单元测试：每类题型批量生成 1000 次，验证答案计算正确、无重复超阈值、数字输入键盘能作答。
4. 按题型作答时限（加减 90s，乘除/混合 180s），超时算错换题。
5. 所有验证题（停止守护、设置放宽）统一按年级出题。

## 第三批：强度 4 与交互

1. 强度 4：无暂停、无任何解锁入口；AI 工具只能加锁。
2. 开始锁机确认页（时长/强度/暂停/防护等级，3 秒倒计时）。
3. 防护等级显示（系统级/悬浮窗/基础）+ 缺失权限提示；必需权限判定纳入悬浮窗。
4. 设置页放宽项改显式保存，取消时回滚 UI 值。
5. 清理：删除 `PomodoroScreen` 与 `unlock_challenge` 路由；二级页隐藏底栏；硬编码颜色改主题令牌。

## 第四批：番茄钟与主题

1. 番茄钟自定义专注/休息/长休息时长与周期（预设 25/5、50/10、90/20 + 自定义），阶段切换通知。
2. 主题拆分“外观（深/浅/跟随）”与“配色”，自定义强调色（对比度校验），锁机页背景/字体定制；JSON 存储并兼容旧 `themeMode`。

## 构建方式：GitHub Actions（本机/手机不编译）

- 每批改动提交到新分支（如 `fix/lock-hardening`），不直接推 main。
- `build-apk.yml` 增加 `./gradlew testDebugUnitTest` 步骤；分支通过 `workflow_dispatch` API 触发构建。
- 轮询运行结果；失败则读日志修复后重推；成功后给出 APK 产物下载链接。
- 合并到 main 由用户决定（或经确认后开 PR）。
- Token：用户在 shell 中以环境变量 `GH_TOKEN` 提供，不写入仓库、git config 或任何文件。

## 验证

- 引入 JUnit，`LockState` 时钟可注入；为篡改、重启、暂停、番茄钟、覆盖锁机、`ChallengeGenerator` 答案正确性写单元测试。
- 每批完成后 `./gradlew assembleDebug` + `./gradlew test`。
- 真机相关（ROM 清后台、Dhizuku 策略、无障碍拦截）无法在此环境验证，需用户实机测试。
